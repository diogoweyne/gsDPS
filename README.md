# ♻️ ResíduosMap — Monitoramento e Análise de Descarte Irregular de Resíduos Urbanos

Projeto desenvolvido para a **Global Solution FIAP** da disciplina de **Differentiated Problem Solving**, com foco na análise matemática do descarte irregular de resíduos urbanos e na proposta de uma solução tecnológica para monitoramento ambiental.

---

## 📖 Sobre o Projeto

O **ResíduosMap** tem como objetivo analisar o comportamento do descarte irregular de resíduos na **Avenida Joaquim de Santana**, localizada no bairro do Butantã, em São Paulo.

Por meio da aplicação de modelos matemáticos e visualização de dados, o projeto busca compreender a evolução do volume de resíduos ao longo do tempo, permitindo identificar tendências de crescimento e apoiar ações preventivas de limpeza urbana.

Além da análise quantitativa, foi proposta uma solução digital para monitoramento e emissão de alertas em áreas críticas de descarte.

---

## 🎯 Objetivos

- Analisar o crescimento do volume de resíduos urbanos.
- Aplicar conceitos matemáticos para modelagem de dados.
- Comparar diferentes tipos de funções para representar o fenômeno estudado.
- Gerar gráficos para facilitar a interpretação dos resultados.
- Propor uma solução tecnológica voltada à sustentabilidade urbana.
